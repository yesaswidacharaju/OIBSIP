
# BMI Calculator

## About
A simple Python BMI Calculator developed as part of the Oasis Infobyte Python Programming Internship.

## Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates Body Mass Index (BMI).
- Displays BMI rounded to two decimal places.
- Classifies BMI into standard categories.
- Handles invalid and negative inputs.

## Formula

BMI = Weight (kg) / Height (m)²

## Technologies Used
- Python 3
- VS Code

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python3 main.py
